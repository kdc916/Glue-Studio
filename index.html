maxVFX Glue Studio 사용 안내

  1. 같은 크기의 PNG 시퀀스를 여러 장 추가하거나 시트 분할을 선택합니다.
  2. 프레임 해상도·열 개수·간격을 설정합니다.
  3. 검은 배경의 화염/연기는 검정 배경 제거를 선택합니다.
  4. 시트/애니메이션/알파 뷰에서 결과를 확인합니다.
  5. PNG, TGA는 시트로, GIF는 애니메이션으로 출력됩니다.

모든 처리는 브라우저 내부에서 이루어집니다. GIF는 256색 및 이진 투명도만 지원하므로 반투명 연기 등의 최종 엔진 텍스처는 PNG/TGA를 권장합니다.
